## Authentication

Two credential types are accepted, sent in the `Authorization` header as
a bearer token.

| Type | Prefix | Lifetime | Notes |
|------|--------|----------|-------|
| API key | `gib_` | Permanent | Long-lived, tied to a person/role, per-minute limit, IP allow-list |
| User token | `tok_` | Minutes | Short-lived, from `/auth/login`, refreshable via `/auth/refresh` |

### Login (password grant)

```http
POST /auth/login
Content-Type: application/json

{"username":"teacher","password":"secret","scopes":"students.read,attendance.write"}
```

Returns a token pair and the linked person:

```json
{
  "data": {
    "token": "tok_...",
    "refreshToken": "ref_...",
    "expiresIn": 120,
    "user": { "tawasulPersonID": "123", "username": "teacher", "surname": "Smith" }
  }
}
```

### Refresh a token

```http
POST /auth/refresh
Content-Type: application/json

{"refreshToken":"ref_..."}
```

### Identify the current credential

```http
GET /auth/me
Authorization: Bearer tok_...
```

Shows the credential type, granted scopes, linked person and roles.

### Logout

```http
POST /auth/logout
Authorization: Bearer tok_...
```

Revokes the current user token (API keys must be revoked in the Gibbon UI).

## Rate limits

| Credential | Source | Default limit | Window |
|------------|--------|---------------|--------|
| API key | key's `rateLimit` setting | configurable | 1 minute |
| User token | `tokenRateLimit` setting | 240 | 1 minute |
| Login attempts | `tokenRateLimit` setting | configurable | 1 minute |

Every response carries `X-RateLimit-Limit`, `X-RateLimit-Remaining` and
`X-RateLimit-Reset` (Unix timestamp). Exceeding the limit returns 429.
Repeated failed logins from one IP are temporarily locked out.

---

## Error format

All errors use the same JSON shape and carry an `X-Request-Id`:

```json
{
  "error": { "code": "forbidden", "message": "This credential does not hold the \"x.write\" scope.", "details": { ... } },
  "meta": { "requestID": "req_a1b2c3d4e5f6a7b8" }
}
```

| Status | Code | Meaning |
|--------|------|---------|
| 400 | bad_request | Invalid JSON or missing required parameter |
| 401 | unauthorized | No credential, or it was not recognised |
| 403 | forbidden | Scope missing, IP blocked, or no role permission |
| 404 | not_found | Resource or record does not exist |
| 405 | method_not_allowed | The HTTP method is not supported on this path |
| 409 | conflict | A record with that unique value already exists |
| 422 | validation_failed | Input failed validation rules |
| 429 | rate_limited | Too many requests in the current window |
| 503 | unavailable | The API or database is not reachable |

## Reading collections

```http
GET /students?page=1&pageSize=25&sort=-surname&search=John&fields=tawasulPersonID,preferredName,surname
Authorization: Bearer gib_...
```

### Query parameters (all collections)

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number, starting at 1. Defaults to 1. |
| `pageSize` | integer | Records per page (max configurable). Defaults to 25. |
| `sort` | string | Sort field. Prefix with `-` for descending. |
| `search` | string | Free-text search across the searchable fields. |
| `fields` | string | Comma-separated list of fields to return. |
| `tawasulSchoolYearID` | integer | Restrict to one school year. |

Each resource also accepts its own `filters` (see the resource table below).
Numeric and date filters accept `<filter>From` and `<filter>To` suffixes.

### Single record

```http
GET /students/GS001234
Authorization: Bearer gib_...
```

## Writing data

Create, update and delete all require the `<resource>.write` scope **and** the
linked Gibbon user's role to hold the matching module action (when role
permissions are enforced). POST returns 201; PATCH/PUT/DELETE return 200.

### Create (POST)

```http
POST /attendance
Authorization: Bearer tok_...
Content-Type: application/json

{"tawasulCourseClassID":"12345","tawasulPersonID":"GS001234","date":"2026-09-18","status":"Present"}
```

### Partial update (PATCH)

```http
PATCH /attendance/ATT001
Authorization: Bearer tok_...
Content-Type: application/json

{"status":"Late"}
```

### Full replace (PUT)

```http
PUT /attendance/ATT001
Authorization: Bearer tok_...
Content-Type: application/json

{"tawasulCourseClassID":"12345","tawasulPersonID":"GS001234","date":"2026-09-18","status":"Present"}
```

PUT replaces the entire record — omit a required field and you get 422.

### Delete (DELETE)

```http
DELETE /attendance/ATT001
Authorization: Bearer tok_...
```

## Bulk operations

Create, update or delete up to 500 records in one transaction. Every item
must succeed or the whole request is rolled back.

```http
POST /attendance/bulk
Authorization: Bearer tok_...
Content-Type: application/json

{
  "items": [
    {"tawasulCourseClassID":"12345","tawasulPersonID":"GS001234","date":"2026-09-18","status":"Present"}
  ]
}
```

Each item is either a new object, an object with the primary key to update,
or `{"op":"delete","id":"ATT001"}` to remove a record.

## Exports

Download an entire resource as CSV — no pagination, one row per record.

```http
GET /students/export
Authorization: Bearer gib_...
Accept: text/csv
```

## Search and aggregation

### Free-text search
`GET /students?search=Smith` — searches the resource's `search` columns.

### Distinct values
`GET /students/distinct?field=tawasulYearGroupID` — unique non-null values for a column.

### Aggregate summary
`GET /attendance/aggregate?by=status` — counts grouped by one or more fields.

## Relation traversal

Follow a foreign-key link from one record to its related record or list:

```http
GET /students/GS001234/attendance
Authorization: Bearer gib_...
```

The relation name appears in each resource's OpenAPI spec under the path
`/{resource}/{id}/{relation}`.

---

## File transfers

File transfer is off by default. An administrator enables it in the Rest API
settings. Once enabled:

```http
GET  /files/{resource}/{id}           # list file fields on a record
GET  /files/{resource}/{id}/{field}  # download (add ?disposition=inline to view)
POST /files/{resource}/{id}/{field}  # attach or replace (multipart or base64 JSON)
DELETE /files/{resource}/{id}/{field}# detach and delete the file
```

Uploads are rejected if the extension is in the forbidden list (`.php`, `.html`,
etc.) or if the file exceeds the configured maximum size (413).

## Composite endpoints

Convenience endpoints that join data across multiple resources in a single call.
Each part is included only when the caller holds the read scope for it.

| Endpoint | Description |
|----------|-------------|
| `GET /students/{id}/profile` | Student, family, enrolment, timetable, attendance summary, recent behaviour |
| `GET /staff/{id}/profile` | Staff member, contract, roles, departments, taught classes, absences |
| `GET /families/{id}/profile` | Family, adults with contact details, children |
| `GET /courses/{id}/overview` | Course, its classes, and enrolment count per class |
| `GET /students/{id}/finance` | Invoices, fees and payments with outstanding totals |
| `GET /students/{id}/timetable` | Timetabled periods for one person, by day |
| `GET /classes/{id}/roster` | Students and teachers attached to one class |

## Webhooks

When enabled, every create/update/delete is POSTed to subscribed URLs as
a `{resource}.created`, `{resource}.updated`, `{resource}.replaced` or
`{resource}.deleted` event. Each delivery carries an `X-Gibbon-Signature`
header: `sha256=` HMAC-SHA256 of the raw body using the subscription secret.

### Subscribe

```http
POST /webhooks
Authorization: Bearer tok_...
Content-Type: application/json

{"name":"Attendance changes","url":"https://hooks.example.com/gibbon","events":"attendance.created,attendance.updated"}
```

---

## Batch requests

Send multiple API calls in one HTTP request to reduce round-trips:

```http
POST /batch
Authorization: Bearer tok_...
Content-Type: application/json

{"requests":[{"method":"GET","path":"/students?pageSize=1"},{"method":"GET","path":"/classes/A24"}]}
```

Returns an array of per-request responses, each with its own status code.
